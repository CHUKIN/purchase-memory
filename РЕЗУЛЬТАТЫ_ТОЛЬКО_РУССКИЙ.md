# Results: Russian only

Owner decision 2026-10-13: the app is Russian only for now.

## What changed
- `app/LocaleContext.ts`: new `LANGUAGE_SWITCH_ENABLED = false`. Set to true to bring the switch and stored preference back.
- `app/AppProviders.tsx`: stored locale (localStorage) is ignored while the flag is false; locale is `ru`. An explicit `locale` prop (stories/tests) still works.
- `app/SettingsSheet.tsx` («Ещё») and `auth/AuthLayout.tsx` (sign-in): language switch rendered only when the flag is true.
- `i18n/i18n.ts`: `shell.more.open` label is now "Ещё: подсказки, выход" / "More: help, sign out". English texts and the `language`/`interfaceLanguage` keys are kept.
- `features/help/helpText.ts` (ru and en): removed the RU/EN switch mention from the sign-in topic. `topics.ts` had none.
- `app/App.test.tsx`: old switch test replaced by two tests (no switch in «Ещё»; stored `en` still gives Russian).

## Checks
- `npm run build` (tsc + vite): passed.
- `npx vitest run`: 36 files, 315 tests passed.

## Limitations
- Unused i18n keys left in place for the later return. `.pm-locale-switch` CSS kept.
- Some English strings (e.g. `common.appNameEnglish`) are untouched.
- Worktree needed `npm ci` (node_modules is untracked).
