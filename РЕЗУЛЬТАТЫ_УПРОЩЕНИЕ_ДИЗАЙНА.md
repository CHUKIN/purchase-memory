# Results: design simplification (2026-10-15)

Owner request: less text and descriptions, icons instead. Frontend only
(`src/PurchaseMemory.Web`), no backend/API changes, swipe review behaviour
unchanged.

## Global patterns
- «Как это работает» text links → `HelpLink` is now a 44×44 «?» icon
  (aria-label «Как это работает: <тема>», same `/help#topic`). It sits in the
  page toolbar (`Page end`), in a section header (`SectionHeader action`) or in
  a sheet toolbar (new `Sheet help` prop) instead of a footnote.
- Back button: chevron only; the previous screen's name is its accessible name.
- Status words → icons: ✓ (`CircleCheck`, success colour) and ⚠
  (`AlertTriangle`, warning colour); the word stays visually hidden for screen
  readers.
- Empty states: icon + title only (descriptions removed). The filtered review
  queue keeps its sentence because it names the hiding filter.
- Short dates in rows: `features/purchases/dates.ts` `formatShortDate`
  («24 авг., 19:12», year only when not current).
- Unused i18n keys removed (ru + en); help `ui.intro`, `ui.contextLink`,
  `ui.welcomeBody` removed from `helpText.ts`.

## Fixes
- No-box line card: «Место строки не найдено…» note is rendered by `LinePhoto`
  inside `.pm-photo-frame` (new `note` prop), at the top of the photo itself,
  so it stays on the photo however narrow it is and clear of the zoom button
  (bottom-right). Used by both the swipe review card and the editor's
  `.pm-sheet-photo`. Checked on the LineReview `NoBox` story.
- Review follow-ups: welcome-card ✕ «Скрыть» gets `pm-icon-button` (44×44);
  «На чём основан ответ» and the receipt «история изменений» toggle are native
  `<button aria-expanded aria-controls>` (`.pm-disclosure`), the coverage h3
  wraps the button instead of sitting inside it; capture list header in parts
  mode renamed «Части одного чека» → «Порядок частей» (no longer repeats the
  selected mode).
- Zoom button 40 → 44 px; icon buttons in items/toolbars 44×44; segment
  buttons min-height 44 px.

## Accessibility
- Every icon-only control has an aria-label (help «?», pencil, filter, ⋯ part
  actions via visually-hidden «Ещё», rate, ✕ new question, back chevron).
- Removed words that carried state (Проверено / Нужно проверить / Исправлено /
  rating names) stay as visually-hidden text.
- Colours unchanged (existing tokens: primary, `--pm-success-text`,
  `--pm-warning-text`, `--pm-muted`).
