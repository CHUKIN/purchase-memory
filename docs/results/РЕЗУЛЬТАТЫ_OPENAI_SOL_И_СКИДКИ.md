## Что сделано
- **Распознавание:** `Pipeline = openai`, `gpt-6-sol`, reasoning Low, detail High, `OpenAiMaximumOutputTokens = 16384`, таймаут 300 с (было 90). Запасной путь — `ollama` с `gemma4:31b-cloud` через локальный демон. Ключ только из `OPENAI_API_KEY`; без ключа приложение стартует и уходит в запасной путь.
- **Инструкция v3 (= v9 эксперимента):** польский, сначала `rawLines`, потом позиции; скидки OPUST/RABAT отдельными строками с минусом. `rawLines` не сохраняются и не пишутся в лог.
- **Скидки (вариант А владельца):** строки с `Kind = Discount` и привязкой к ближайшему товару выше; скидка на весь чек (маркеры podsuma/suma/na paragon… или скидка больше товара) — без привязки, подпись «Скидка · на весь чек». Скидки не создают товаров каталога и не участвуют в сопоставлении. Сумма строк со скидками сравнивается с итогом. API отвергает противоречие «тип ↔ знак суммы» с 400.
- **UI:** `ReceiptDiscountLine.tsx` — скидка строкой под товаром, «цена после скидки» (скрыта при ≤ 0), редактирование и удаление; a11y-подписи ru/en; 7 stories.
- **Миграция** `20260924142126_AddReceiptLineKind`: `Kind TEXT NOT NULL DEFAULT 'Product'`, `DiscountedItemPosition INTEGER NULL`. Проверена на свежей и старой БД (в scratchpad).
- **Автобэкап перед миграцией** (`DatabaseMigrationBackup.cs`): при неприменённых миграциях — снимок в `data/backups/purchases-<utc>-before-<migration>.db`; при сбое миграция не применяется, приложение не стартует.
- Исправлено попутно: `FallbackPipelines` по умолчанию пустой (раньше конфиг дописывался к `["apple"]`); `appsettings.Development.json` больше не переключает на Apple.
