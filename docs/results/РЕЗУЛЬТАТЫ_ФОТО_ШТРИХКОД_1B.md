## What was built
- Variant A (big gallery, home tiles, full-screen scan result) and variant B
  (photo strip, home button, result sheet over camera; default). Switch:
  «Ещё» → Настройки → «Вид фото и сканера».
- `/scan`: known code → last purchase, cheapest store, rating, «Больше не
  покупать»; unknown → link to own product, Open Food Facts name (barcode only
  sent, 6 s timeout), «Запомнить на потом».
- Product card: photos (take / library, main, delete), barcodes (scan / manual),
  avoid flag. Line review sheet: photo / scan for the line's product. Catalog
  thumbnails. Help topic `product-scan` (ru/en).
- Storage: device only (IndexedDB `productMediaStore`), cleared on sign-out.
- Decoder `barcode-detector` 3.2.2 + `zxing-wasm` 3.1.3 (direct deps), lazy;
  wasm 1.09 MB (464 kB gzip) not precached → first scan needs network.

## Known limitations
- UPC-E not expanded to UPC-A/EAN-13 (rare in PL).
- Sign-out `clear()` not queued behind in-flight writes; orphan photo bytes on
  a failed metadata write (device only).
- OFF called from the browser (moves behind the backend in Stage 2).
- Not verified (needs the owner's iPhone): decode speed, torch, safe areas,
  camera after backgrounding (iOS may re-ask permission), stacked modals feel.
