# Results: mobile fixes (iPhone date filters, category select, feed card, tag nits)

Date: 2026-10-12.

## What changed

1. **Date filters on iPhone.** New shared `DateInput` (`src/design-system/components/DateInput/`):
   native `<input type="date">` with `appearance: none`, `min-width: 0`, `width: 100%`,
   left-aligned value (`::-webkit-date-and-time-value`). When the field is empty, iOS/iPadOS
   WebKit shows a muted «Любая дата» / "Any date" hint (`common.dateEmpty`). The hint is CSS
   generated content behind `@supports (-webkit-touch-callout: none)`, so desktop browsers keep
   their own «дд.мм.гггг» hint and the `<label>` text does not change. Used in the feed filter
   (`PurchaseFeed.tsx`) and in the analytics plan editor (`PlanFilters.tsx`). Review follow-up:
   `DateInput` also takes `type="datetime-local"`. It is now used for «Дата и время» in the purchase
   editor (`PurchaseDetailPage.tsx`); when that field is empty it shows «Дата не указана»
   (`purchaseEdit.unknownDate`). Stories: `DateInput.stories.tsx` (Empty, Filled, DateTimeLocal).
   In the feed, the `.dates`
   labels also got `min-width: 0`, because a grid item's automatic minimum width is its content width.
2. **Category select.** New shared `CategoryOptions` (`features/categories/CategoryOptions.tsx`)
   used by `CategoryFilterField` (feed, catalog, review queue) and `CategoryPicker` (editors).
   Inside an optgroup the options are now short: "Вся группа" (filter) / "Без подкатегории"
   (picker), then child names only. **Decision:** only the *selected* option renders its full
   text («Молочное и яйца / Сыр», «Молочное и яйца — вся группа»; in the picker the plain group
   name). A closed select shows only the selected option's text, and a bare «Прочее» there would
   be ambiguous. New i18n keys: `filters.wholeGroupShort`, `categories.groupWithoutSubcategory` (ru + en).
3. **Feed card at 320 px.** Below 22.5em (~360 px) the card becomes a single column. The
   total and the status badge move below the meta as one wrapping row, so the badge can no
   longer overlap the date.
4. **Tag suggestions focus.** `TagSuggestions` now waits until the accept has finished before it
   moves focus, because a disabled button cannot take focus. `ProductTags`: when accepting the
   last suggestion removes the whole suggestions block (every household tag is now on the
   product), focus goes to the «Теги» heading (`tabIndex=-1`). This happens only if focus
   fell to the page body.
   Backend: the catch-all in `AnthropicTagSuggester` now passes the exception to the logger.
   It is still event 3412; `RequestFailed` got an optional `Exception?` parameter. Provider errors
   that are already categorised are still logged without the exception.
5. **Rename** `AnthropicServiceException` → `AnthropicProviderException`. The Anthropic SDK 12.55.0
   defines `AnthropicServiceException`; the new name does not exist in the SDK. Usages and tests
   were updated.

## Limitations / follow-ups

- Help text (owned by another agent): `helpText.ts` still cites the option
  «Молочное и яйца — вся группа». In the open list it is now «Вся группа» under the group
  heading; the long form appears only once it is selected. The help text should say something like
  «выберите в группе «Вся группа»».
- `CapturePage.tsx` (owned by another agent) still has a raw `datetime-local` in the legacy
  review form. It would benefit from `DateInput type="datetime-local"`; apply that after the merge.
- The analytics plan editor was not screenshotted on iOS. It uses the same `DateInput`, and its
  fields already had `min-width: 0`.
- iOS shows the chosen date in the device locale format (for example "12 Oct 2026"). The app does not control that format.
