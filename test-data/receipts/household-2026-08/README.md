# Личные чеки владельца (август 2026)

20 реальных фотографий чеков владельца проекта и его семьи, присланы напрямую
в чат 2026-08-29 для сравнения подходов к локальному распознаванию (Track B,
см. `ИДЕИ_ЛОКАЛЬНЫЕ_МОДЕЛИ.md` в корне репозитория). В отличие от
`test-data/receipts/public/`, это не публичные образцы — личные покупки,
поэтому папка не публикуется и не redistributes: см. правило в `.gitignore`.

## Состав

19 польских чеков (Dodo Pizza, E.Leclerc, Lidl, McDonald's ×2, Auchan ×2,
Carrefour ×4, Żabka, Lviv Croissants ×2, Suntago, Billy's American
Restaurants, Mleczarnia Posińska) и 1 немецкий (Rossia, Берлин) — разные сети,
форматы чека и качество печати (есть выцветшие термопринтером).

Файлы `receipt_01.jpg` … `receipt_20.jpg`, без переименования по магазину —
соответствие смотри по содержимому изображения.
